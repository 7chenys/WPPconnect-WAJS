    安装

    固定安装当前版本：

    npm install @yanmontain/wa-js@4.6.0 --save-exact

    如果现有项目仍通过 @wppconnect/wa-js 解析依赖，可以使用 npm alias：

    {
      "dependencies": {
        "@wppconnect/wa-js": "npm:@yanmontain/wa-js@4.6.0"
      }
